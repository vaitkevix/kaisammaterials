# SH | Kaisāmmateriāls

Ietvara lapa, kas atver Apps Script lietotni "Kaisāmmateriāls" (sāls, smilts, mix piegādes pieteikumi)
pa visu telefona ekrānu (bez baltām joslām augšā un apakšā) un ļauj to pievienot sākuma ekrānam kā lietotni.

Dati un loģika atrodas Google Apps Script / Google Sheets — šī lapa tikai ielādē lietotni.
